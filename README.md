# Beer Debt (Android)

Android port of [Beer Debt iOS](https://github.com/watsoncolin/beer-debt-ios).
Native Kotlin + Jetpack Compose, targeting feature parity with the iOS app.

**Drink now. Run later.** Every beer you log costs a mile. Runs from Health
Connect pay it back. Ignore the tab and interest starts.

## Layout

| Module | What it is |
|---|---|
| `engine/` | The accounting engine, pure Kotlin (no Android). Models with the same JSON as the iOS `ledger.json`, and `BalanceEngine`, a port of the Swift replay. Tested against fixtures generated by the Swift engine. |
| `app/` | The Compose app: JSON ledger store (same file format as iOS), Health Connect sync (Changes API, foreground + hourly WorkManager poll), run notifications, weekly summary notification, running streaks (interest pauses from day two), Glance home screen widget, Home / Your Debt / Runs / Settings / Privacy / onboarding, forest theme. |

## The contract with iOS

`engine/src/test/resources/cases.json` is generated in the iOS repo
(`scripts/fixtures.sh`) by running the Swift engine over 64 scenarios. The
Kotlin engine must reproduce every number to 1e-6. When the iOS engine
changes, regenerate there and copy the file here; the test fails loudly if
the ports drift.

## Setup

- JDK 17+. Android Studio's bundled JDK works:
  `export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"`
- Gradle 9.7 via the wrapper; AGP 9.4; Kotlin 2.4.

```sh
./gradlew :engine:test           # the fixture suite; no Android SDK needed
./gradlew :app:assembleDebug     # the app; AGP downloads missing SDK packages
```

`scripts/emulator-bootstrap.sh` installs the emulator and an API 36 image and
creates a Pixel AVD; `scripts/screenshots.sh` boots it, seeds demo data, and
screenshots every screen into `docs/screenshots/`.

`local.properties` points `sdk.dir` at `~/Library/Android/sdk`. With the
license hashes in `$SDK/licenses/`, AGP installs the platform and build
tools it needs on first build; only the emulator and system images need
`sdkmanager` (or Android Studio's device manager).

## Release

Signed AABs are built by the manual `Release to Play` workflow with the
upload key from repository secrets; `docs/release.md` has the Play Console
checklist, and `docs/play/` holds the listing copy and graphics.

## Stack

- Kotlin 2.4, Jetpack Compose (BOM 2026.09), Material 3, forced dark theme to match iOS
- kotlinx.serialization for the ledger file (same JSON as iOS)
- Health Connect (`connect-client`) for running exercise sessions, read-only
- No backend, no accounts, no analytics
